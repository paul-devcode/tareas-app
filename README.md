# App de tareas

Pequeña aplicación de gestión de tareas desarrollada con Node.js, Express y SQLite.
Permite crear, completar y eliminar tareas de forma sencilla.

## Tecnologías

* Node.js
* Express
* SQLite
* HTML, CSS y JavaScript

## Funcionalidades

* Crear tareas
* Marcar tareas como completadas
* Eliminar tareas
* Guardado en base de datos local

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```
git clone https://github.com/paul-devcode/tareas-app.git
```

2. Instalar dependencias:

```
npm install
```

3. Ejecutar el servidor:

```
node index.js
```

4. Abrir en el navegador:

```
http://localhost:3000
```

## Sobre el proyecto

Este proyecto lo he desarrollado como práctica de backend para entender cómo crear una API con Express y conectar una base de datos SQLite.
